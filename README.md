## 原生、家宽、双ISP：三个词说的不是一件事

原生 IP 指 IP 的注册归属地和服务器所在地一致，由当地运营商持有，不是从别的国家广播过来的地址。家宽 IP 指这个 IP 在数据库里的持有方是家庭宽带运营商，属性标为 residential。双 ISP 通常指 IP 段同时登记在两家运营商名下，或者机器接入两条运营商线路，不同商家口径不完全一样，看到这个词要回产品页确认它具体指哪种。

三者叠加，才是“原生家宽双 ISP IP”。WePC 的产品命名里这几种说法混着用，光是英国一个机房就有两款产品，差 4 澳元，差的正是属性：

判断一台 VPS 的 IP 是不是真住宅，可以按三步走。

**第一步，看商家自己怎么标。** WePC 列表页出现了“原生家宽 IP”“原生 IPv4”“原生 IDC IPv4”“非家宽 IP”四种写法。新加坡两个产品最典型：16.90 澳元那款写的是“新加坡原生 IDC IPv4”，24.90 澳元那款才是“新加坡原生 IPv4”并注明直播建议中转。价格低的那个是机房 IP，拿它做住宅 IP 的活会踩空。

**第二步，拿 IP 去数据库查。** 下单前用 ipinfo、scamalytics 这类工具查 ASN 和 usage type，看它标的是 ISP、business 还是 hosting。有第三方测评对 WePC 西班牙那款做过实测，所测实例的 IP 被多个数据库判为西班牙原生、住宅属性，能解锁西班牙 TikTok、ChatGPT、Netflix、Disney+，但解锁不了 Gemini。同一批测评对英国原生家宽款的结论是：IPv4 归属英国原生，所测实例被判为商业属性、非住宅，虽然能解锁英国 TikTok、ChatGPT、Claude、Netflix。单个实例说明不了整批 IP 段，但这正好说明“官方写家宽”和“数据库判住宅”之间可能有一层落差，买之前自己查一次最稳。

**第三步，看 IP 段新旧和地区匹配。** 目标观众在哪，节点就选哪。TikTok 的推流会优先把直播推给和 IP 归属地匹配的用户，位置对了，冷启动会顺很多。IP 段太老、被反复用过，欺诈分降不下来，这类信息商家一般不会写，只能自己查。
